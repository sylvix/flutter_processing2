# `lerp()`

```dart
double lerp(num start, num end, double percent)
```

Вычисляет число между двумя числами с заданным шагом.
Параметр `percent` указывает, насколько нужно интерполировать между двумя значениями: значение 0.0 соответствует первой точке, 0.1 — очень близко к первой точке, 0.5 — это середина между двумя точками, и так далее.
Функция `lerp` удобна для создания движения по прямой траектории и рисования пунктирных линий.

## Пример

```dart
@override
void draw() {
    int x1 = 60;
    int y1 = 40;
    int x2 = 320;
    int y2 = 360;
    line(x1, y1, x2, y2);
    for (int i = 0; i <= 40; i++) {
        var x = lerp(x1, x2, i / 40) + 40;
        var y = lerp(y1, y2, i / 40);
        point(x, y);
    }
}
```
